# EDURange Cloud Documentation

Official documentation for [EDURange Cloud](https://edurange.cloud), a Kubernetes-powered cybersecurity education platform.

**Links:** [Website](https://edurange.cloud) | [Source Code](https://github.com/Rydersel/EDUrange_Cloud)

## About

This documentation site provides comprehensive guides for installing, configuring, and using EDURange Cloud. It covers everything from basic concepts to advanced technical details for administrators, instructors, and developers.

## Development

This documentation site is built with [Nextra](https://nextra.site), a powerful documentation framework built on Next.js.

### Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to view the documentation locally.

### Building

```bash
npm run build
```
